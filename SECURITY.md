# Segurança

Não publique credenciais, dados pessoais ou detalhes exploráveis em issues públicas. Se a opção estiver disponível, use a aba Security → Report a vulnerability deste repositório. Caso contrário, abra uma issue sem detalhes técnicos solicitando um canal privado ao mantenedor; aguarde esse canal antes de enviar evidências sensíveis.

O helper executa o comando informado com as permissões do usuário, sem isolamento. Revise comandos, dependências e configuração antes de executar. O timeout não garante encerrar processos descendentes. Logs personalizados e relatórios de scanners podem conter dados sensíveis.

Esta versão inicial não possui SLA de resposta. Ferramentas de segurança citadas não são distribuídas pela Atlas; disponibilidade, licenças e atualização dependem de seus mantenedores.
